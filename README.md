# 📚 Library Management System

## 📌 Project Overview
A Java-based Library Management System designed to manage books, students, and faculty operations efficiently.

## 🎯 Features
- Add Books
- Register Students
- Register Faculty
- Issue Books
- Return Books
- View Available Books

## 🛠 Technologies Used
- Java
- OOP Concepts
- File Handling / Collections

## 🚀 Purpose
Built to understand object-oriented design and real-world system implementation.
